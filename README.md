# ResumeX AI V2

Professional local resume intelligence dashboard.

## Features

- PDF / DOCX / TXT resume analysis
- ATS-style score
- Skill detection
- Resume section detection
- Strengths and improvement suggestions
- Job description matching
- Matched and missing skills
- Professional responsive UI
- Automatic virtual environment
- One-click Windows `run.bat`

## Run

Extract the project and double-click `run.bat`.

The first launch creates `.venv` and installs dependencies.

Open: `http://127.0.0.1:5000`

## Important

The ATS score and job matching are heuristic analysis features, not a hiring decision or guarantee of recruiter results.
